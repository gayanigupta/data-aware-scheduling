% Text of the abstract (one page maximum, including references)
Disaster-response workflows, such as flood forecasting and wildfire
tracking, move large intermediate results between dependent tasks. In a
federated fog system, where a task is placed decides whether its input
arrives before the deadline or not. We model this as a mixed-integer
program that chooses, for every task, both the fog node it runs on and the
fraction of the task it computes, given the data size on each edge, the
bandwidth of each link, node eligibility, and one end-to-end deadline.
From this model we build four schedulers: the exact MILP, a randomized
rounding of its linear relaxation, a data-aware greedy heuristic, and a
genetic algorithm. We compare them on generated DAGs while varying the
deadline slack, the workflow size, the number of federated nodes, the link
bandwidth, and the task-failure rate, and we score each method against a
maximum-accuracy bound. The MILP gives the best accuracy when the deadline
barely fits. The greedy method reaches the same bound at 1000 tasks in a
fraction of a second, making it the only approach that is both fast and
bound-level at scale. A bandwidth-blind baseline shows why accounting for
data movement matters: it achieves bound-level scores but produces late
schedules once links degrade, while the data-aware methods remain
feasible. This work extends our earlier conference
study~\cite{gupta2025efficient} with the complete formulation, an accuracy
bound, experiments on failures and link degradation, and an analysis of
where each solver stops scaling.
